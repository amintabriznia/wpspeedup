بهینه‌ساز پیشرفته سرعت وردپرس برای شرایط فیلترینگ ایران

== Description ==

این افزونه بهینه‌ساز کامل سرعت وردپرس برای کاربران ایرانی است. 
تمام درخواست‌های خارجی که در ایران فیلتر هستند و باعث کندی سایت می‌شوند مسدود یا جایگزین محلی می‌شوند.

= ویژگی‌های نسخه 4.0.0 =

* مدیریت فونت دلخواه — انتخاب از فونت‌های فارسی محبوب یا آپلود فونت سفارشی
* مسدودسازی سایت‌های دلخواه — بلک‌لیست سفارشی برای دامنه‌های خارجی
* وایت‌لیستینگ — مدیریت دامنه‌های مجاز با پریست درگاه‌های بانکی ایرانی
* دو حالت فیلتر — بلک‌لیست (پیشنهادی) یا وایت‌لیست (حداکثر امنیت)
* تست دسترسی دامنه — بررسی آنلاین دسترسی به هر دامنه
* لاگ درخواست‌ها — مشاهده لاگ مسدودسازی‌ها
* پشتیبان‌گیری تنظیمات — خروجی/بازیابی تنظیمات (JSON)
* پنل مدیریت تب‌بندی شده — رابط کاربری حرفه‌ای و RTL
* پشتیبانی Elementor و WooCommerce
* سرو محلی jQuery, jQuery UI, Bootstrap, Font Awesome
* جایگزینی Gravatar با آواتار پیش‌فرض محلی
* حذف Bloat وردپرس (Emoji, Embeds, RSS, XML-RPC, ...)

== Installation ==

1. فایل ZIP را در wp-content/plugins آپلود کنید
2. افزونه را از بخش پلاگین‌ها فعال کنید
3. به تنظیمات → بهینه‌ساز ایران بروید
